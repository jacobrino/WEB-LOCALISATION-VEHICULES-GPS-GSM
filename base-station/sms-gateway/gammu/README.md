# Configuration Gammu (gammu-smsd)

Ce dossier contient la configuration utilisée par **gammu-smsd** sur la station de base.

## Fichiers
- `gammu-smsdrc` : fichier de configuration principal de gammu-smsd (copié depuis l'environnement de stage).

> Remarque : Il faut adapter uniquement les chemins (spool, logs) et le port du modem (`device`) selon ta machine.
